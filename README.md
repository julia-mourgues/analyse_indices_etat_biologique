# Analyse croisée des tendances spatio-temporelles de 4 compartiments biologiques des cours d'eau normands: Poissons, Diatomées, Macroinvertébrés benthiques et Macrophytes.
Ce dépot contient les script relatifs à l'analyse croisée des tendances spatio-temporelles des communautés biologiques étudiées dans le cadre de la DCE Normandie.
Ce travail a été effectué dans le cadre de mon stage de master 2.
A l'issue du projet, des fiches par stations sont générées permettant de visualiser l'évolution de l'état biologique des chaque station ainsi que des informations environnementales et sur les communautés.
